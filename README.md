# STOCKROOM · 자재관리

HTML/CSS/JavaScript만 사용한 정적 자재관리 앱. 데이터베이스, 백엔드, 외부 라이브러리를 사용하지 않습니다.

## 조사 요약
2026-10-28 조사. Odoo 및 Zoho 공식 제품 안내의 일반적인 자재관리 특징:
- 품목 분류, 규격·코드 관리
- 창고와 위치별 재고 확인
- 입출고 추적 및 수량 조정
- 재주문/부족 재고 알림
- 재고 평가와 분석

출처:
- https://www.odoo.com/app/inventory-features
- https://www.zoho.com/us/inventory/inventory-management-system/

이 앱에서는 자재 CRUD, 창고·위치·거래처 필드, 입출고, 안전재고 알림, 요약과 차트, 검색·필터·정렬·페이지 이동, JSON 백업·복원을 구현했습니다. 실제 발주·결제·바코드·다중 사용자 권한은 포함하지 않습니다.

## 실행 및 배포
정적 웹 서버에서 index.html을 여세요. data.json을 fetch하므로 파일을 더블클릭하는 file:// 실행은 지원하지 않습니다. GitHub Pages에서 main 브랜치 / (root)를 선택하면 배포됩니다. 빌드나 패키지 설치가 필요하지 않습니다.

## 데이터
초기 data.json: 가상 자재 12개, 창고 3곳. 최초 실행 후 변경은 localStorage의 stockroom-material-v1 키에 JSON으로 저장됩니다. GitHub의 data.json 자체는 수정되지 않습니다. 같은 도메인의 다른 앱과 저장 키를 분리했습니다. 내보내기는 version, items, movements 전체를 저장합니다. 가져오기는 JSON 형식·필수 필드·중복 코드·수량 범위를 검증하고 확인 후 전체 교체합니다. 삭제된 품목의 과거 이력도 유지합니다.

## 주의 사항
개인용·학습용 브라우저 앱입니다. 서버 동기화와 로그인은 없으며, 브라우저 데이터 삭제 시 기록이 사라집니다. 주기적으로 JSON 백업을 저장하세요. 같은 브라우저의 여러 탭을 동시에 편집하지 마세요. 자동 백업 다운로드는 브라우저 다운로드 설정의 영향을 받습니다. 수량은 소수 셋째 자리, 단가는 정수 원 단위로 지원합니다. 입력 상한은 10억, 최대 자재 5,000개·이력 50,000개이며 저장 공간 제한이 먼저 발생할 수 있습니다. JSON 가져오기는 10MB 이하를 지원합니다.
