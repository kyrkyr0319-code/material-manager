일반적인 자재관리 프로그램의 특징

Odoo와 Zoho Inventory의 공식 기능 안내를 참고하여 품목 분류, 위치별 재고, 입출고 추적, 재고 조정, 부족 알림, 재고 분석을 핵심 기능으로 정리했습니다.

  • 품목 관리: 코드, 이름, 규격, 단위, 거래처
  • 재고 현황: 보관 창고·위치와 수량 확인
  • 입출고 추적: 입고·출고·조정 내역 기록
  • 보충 관리: 안전재고 기준 부족 품목 확인
  • 분석: 재고 평가액과 분류별 현황

일반 제품의 발주 자동화, 바코드, 다중 사용자 권한 등은 이 정적 앱에 포함하지 않았습니다.

데이터 저장 방식

data.json의 가상 데이터를 최초 로드하고, 변경 내용은 localStorage에 JSON으로 저장합니다. 서버·데이터베이스·로그인은 사용하지 않습니다. 저장 데이터는 다른 기기와 공유되지 않으며, 브라우저 데이터 삭제 시 사라집니다. 파일 백업을 권장합니다. 같은 브라우저의 여러 탭에서 동시에 편집하지 마세요.

JSON 가져오기는 전체 데이터를 교체합니다. 형식 검증 후 교체 전에 확인하며, 기존 데이터는 자동 백업 파일로 내려받습니다.
